# Prioriza

Aplicativo web para apoiar decisões sobre gastos com base em saldo, compromissos, reserva mínima, urgência e prioridade.

## Stack inicial
- Next.js + React
- TypeScript
- Tailwind CSS
- PostgreSQL + Prisma (próxima etapa)

## MVP
1. Dashboard financeiro
2. Cadastro de gastos
3. Classificação P1–P4
4. Cálculo do dinheiro disponível para decisões
5. Explicação da recomendação
